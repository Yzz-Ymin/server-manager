# macOS 安装包

- `ServerManager-1.0.0-macos-x86_64.dmg`：打开后拖入 Applications。
- `ServerManager-1.0.0-macos-x86_64.zip`：解压后拖入 Applications。
- `ServerManager-1.0.0-source.zip`：对应源码、图标及文档。
- `SHA256SUMS`：下载校验清单，使用 `shasum -a 256 <文件名>` 核对。

要求 macOS 13+（Intel）及 Python 3.10+。应用仅做本地签名，未经过开发者证书签名或 Apple 公证。首次启动为空配置，账号、私钥和密码均须由用户自行提供。
