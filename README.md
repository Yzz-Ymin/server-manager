# Server Manager

一个轻量的原生服务器管理工具：按别名和分组管理 SSH 连接，使用系统凭据库保存密码，提供连接验证、SSH / SFTP 终端和命令行任务入口。

## 功能

- 中文分组、搜索和筛选，新增、编辑、删除本机连接配置。
- 密码或私钥认证，原生文件选择器，主机指纹确认。
- SSH 与可选 sudo 验证；保存失败自动恢复原有配置和凭据。
- sudo 可单独填写，也可明确选择与 SSH 登录密码一致。
- 菜单栏入口、Dock / 任务切换，以及有明确父子关系的模态窗口。
- CLI 执行已有操作或一次性命令，复用系统凭据，无需将密码写入脚本。

## 使用

打开应用，新增服务器，填写地址、账号和认证方式；独立核对主机指纹后保存。只有 SSH 和已选择的 sudo 验证成功才提交配置。关闭窗口会保留菜单栏入口，菜单中的“退出”才结束应用。

SSH / SFTP 打开系统 Terminal。SFTP 是交互式客户端，并非图形文件浏览器；终端里的交互式 sudo 仍由用户输入。非交互命令可通过 CLI 使用已保存的 sudo 凭据。

## 凭据与边界

密码和私钥口令保存在系统钥匙串，配置文件只记录引用和连接元数据；私钥保留在用户选择的位置。主机密钥严格校验，不自动修改远端权限或配置。

该设计减少密码进入参数、配置与日志的机会，不构成同一系统用户下的强隔离。已知密码替换也不是通用脱敏工具，执行命令前仍应检查其权限与输出范围。连接中断或超时不保证远端命令已经停止，部署等写入操作不应盲目重试。

当前任务执行面向 Linux / POSIX 远端；尚未实现 Windows PowerShell 远端任务、MFA、跳板机或要求交互终端的 sudo。删除连接只影响该连接的本机配置和凭据，不修改服务器。
