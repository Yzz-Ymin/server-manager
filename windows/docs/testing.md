# 测试说明

`scripts/test.ps1` 先构建解决方案，再执行表单状态与回环 SSH 集成测试。`-SkipSsh` 可只运行界面与本地存储检查。Python 依赖仅用于测试，不参与应用运行或安装包。

覆盖范围：别名及连接校验、密码/无口令私钥/加密私钥认证、主机密钥拒绝、SSH 与 sudo 失败回滚、旧凭据保留、账号切换、真实退出码、超时、一次性操作、SFTP、凭据删除范围，以及 sudo 同密码与认证表单状态。界面检查还覆盖已保存连接首次加载、从托盘恢复时读取磁盘变更、完全退出后重开、首次安装空目录，以及配置路径异常的明确报错。迁移检查覆盖普通与隔离目录合并、重复记录去重、源文件保留、同名冲突保护、中断后续迁移，以及删除记录不被旧缓存重新导入。SSH 测试强制使用带 BOM 的 UTF-8 控制台编码，覆盖跨主机标准输入编码差异。

测试仅监听回环地址，动态生成秘密和密钥。测试凭据使用独立命名空间，并在结束时删除；报告和空白表单预览写入 `artifacts/tests`，不包含真实服务器信息。

其他主机验收时，应由用户在原生窗口录入测试账号并确认指纹，分别检查 SSH、sudo、SSH/SFTP 终端、文件选择和模态窗口层级。回环协议测试不能代替真实 Linux 环境的完整验收。

GitHub Actions 的 Windows 工作流会在全新检出中运行上述测试并打包，报告与未签名开发包作为构建产物保留。EXE/DLL 执行被应用控制拒绝时，测试属于未执行，不能将构建成功视为测试通过。
